# Tây Du Ký MCP

MCP STDIO dùng `@modelcontextprotocol/sdk`, theo cấu trúc của project mẫu `mcp-trends-hub`.

## Tools
- `tay_du_ky_ke_chuyen`
- `tay_du_ky_tom_tat`
- `tay_du_ky_hoi_dap`
- `tay_du_ky_nhan_vat`

## Local
```bash
npm install
npm run build
npm start
```

## imcp.pro sau khi package đã được publish lên npm
- Mode: STDIO
- Command: `npx`
- Arguments: `-y`, `tay-du-ky-mcp`

Không cần biến môi trường.
